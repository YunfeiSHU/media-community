## 登录系统

### 技术设计：

#### 注册

```
POST /api/v1/auth/register
```

请求：

```
{
    "username": "yunfei",
    "password": "Abc123456"
}
```

需要完成：

1. username 非空
2. username 长度校验
3. username 唯一
4. password 长度 8～20
5. ~必须包含大写字母~
6. ~必须包含小写字母~
7. ~必须包含数字~
8. BCrypt 加密密码
9. 写入 MySQL

返回：

```
{
    “code": 0,
    "message": "success",
    "data": null
}
```

------

#### 登录

```
POST /api/v1/auth/login
```

请求：

```
{
    "username": "yunfei",
    "password": "Abc123456"
}
```

流程：

```
username
   ↓
查询 User
   ↓
用户存在？
 ┌─┴─┐
否   是
│     │
失败  查询 password_hash
          ↓
       BCrypt
          ↓
      密码正确？
       ┌──┴──┐
      否     是
      │       │
     失败    登录成功
```

返回：

```
{
    "code": 0,
    "message": "success",
    "data": null
}
```

### 数据表

#### user

```
CREATE TABLE user (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(32) NOT NULL,
    password_hash VARCHAR(100) NOT NULL,
    status TINYINT NOT NULL DEFAULT 1,
    created_at DATETIME NOT NULL,
    updated_at DATETIME NOT NULL,

    UNIQUE KEY uk_username (username)
);
```

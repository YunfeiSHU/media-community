| 项目 | 实际值 |
| --- | --- |
| 操作系统 / JDK | Windows / Java 22 |
| Spring Boot | 3.3.5 |
| 构建命令 | `mvn -q clean test` |
| 测试框架 | JUnit 5 + Spring Boot Test + MockMvc |
| 数据库 / Redis | 不参与：本套用例不连 MySQL、Redis |
| 测试层级 | `@WebMvcTest` + MockMvc（HTTP 契约、参数校验、身份头）；纯单元测试（JWT 签发与验签） |
| 替身 | Mockito `@MockBean`：`AuthService`、`LoginRateLimitService`、`VerificationService` |
| 执行日期 / 报告 | 2026-09-27 / `target/surefire-reports/` |

结果：**2 个测试类、21 个用例**，失败 0、错误 0、跳过 0（`AuthControllerWebMvcTest` 18 个 + `JwtTokenServiceTest` 3 个）。

断言统一走 MockMvc 的 `jsonPath`。Java 侧启用了 `spring.jackson.default-property-inclusion: non_null`，`null` 字段会整体消失，因此空 `data` 一律用 `doesNotExist()` 断言，而不是断言 `"data": null`。

## 3. 覆盖到的失败场景

| 场景 | 期望响应 | 用例 |
| --- | --- | --- |
| 凭据错误 | 400 / `40000`，且不清零限流计数 | L-002 |
| 登录 IP 超限 | 429 / `42901` / `登录请求过于频繁` | L-003 |
| 缺少 `Authorization` 请求头 | 401 / `40101` | O-002 |
| 强制下线调用者不是 ADMIN | 403 / `40301`，业务层不执行 | F-002、F-004 |
| 强制下线缺少身份头 / 只伪造旧 `uid` 头 | 401 / `40101`，业务层不执行 | F-003、F-005 |
| 联系方式已注册 | 400 / `40000` | R-003 |
| 请求参数缺失 | 400 / `40001`，消息含字段名 | P-001 |
| 请求体枚举值非法 | 400 / `40001`，不落到 50000 | V-003 |
| Access Token 已过期 | 验签抛 `ExpiredJwtException`，由调用方转 `40101` | J-003 |

## 5. 已确认的行为

- 登录响应结构：`uid` / `accessToken` / `refreshToken` / `accessTokenExpiresIn=1800` / `refreshTokenExpiresIn=604800`。
- 登录限流只统计失败尝试：成功清零、失败不清零、超限返回 429 / `42901`。
- 强制下线的授权只认网关注入头：非管理员 403 / `40301`、无身份头 401 / `40101`、查询参数伪造角色无效、已废弃的 `uid` 头不再被信任。
- 缺请求头映射为 `40101`（不被兜底成 50000），请求体枚举非法映射为 `40001`。
- 空响应体不带 `data` 字段（`non_null` 序列化配置）。
- JWT 的 `iss`/`sub`/`aud`/`jti`/`role`/`iat`/`exp` 正确，过期 Token 验签被拒绝。
- 验证码：学习模式回传 6 位码，`expose-code=false` 时不回传。
- 注册：手机号与邮箱两条路径均返回 `code=0` 且无 `data`，重复注册返回 `40000`。

## 6. 未覆盖的部分

- **Service 层编排**：`AuthService`（登录/注册/刷新）、`SessionService`（Lua 轮换、SCAN 删除）、`JwtBlacklistService`、`VerificationService`、`LoginRateLimitService` 目前没有单测，只能由 Controller 契约测试间接约束。
- **真实中间件**：`pom.xml` 仍引 Testcontainers `1.19.8`，但仓库内没有集成测试类；Redis Lua 原子轮换、MySQL 唯一索引并发、`SCAN` 删除均未在真实实例上验证。
- **网关鉴权链路**：auth-service 无 Access Token 过滤器，黑名单拦截在 `gateway-service`，本套测试不覆盖。
- **Redis 不可用**：连接拒绝时返回 500，尚未转成统一业务错误。
- **Dubbo 跨进程**：`UserServiceClient` 未参与任何用例，注册编排中的远程调用只用 Mock 替身。
- **并发与压力**：不含任何并发/压测用例，刷新令牌的原子性只有代码层面的 Lua 保证，没有测试证据。
- **多实例部署**：K8s 下 2 副本共享同一 Redis 时 Session/黑名单的行为未验证。

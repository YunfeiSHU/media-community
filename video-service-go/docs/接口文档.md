# video-service-go · 接口文档

> 服务端口：**9001** ｜ 基础路径：`/api/v1` ｜ 健康检查：`/healthz`、`/readyz`
> 契约定稿：v1.0（阶段一）。字段一旦发布不再删除，只做新增。

## 1. 通用约定

### 1.1 统一响应体

```json
{ "code": 0, "message": "success", "data": { } }
```

- `code = 0` 成功，其它见 §1.4。
- 失败时 `data` 为 `null`。
- 时间格式 `RFC3339`（`2026-09-27T10:30:00+08:00`）。

### 1.2 身份传递（与 Java 体系一致）

| 项 | 约定 |
| --- | --- |
| uid 来源 | 请求头 `X-User-Id`（网关从 JWT `sub` 注入；直连时手工携带） |
| 角色来源 | 请求头 `X-User-Role`，取值 `ADMIN` / `user`，缺失按 `user` |
| JWT | 本服务**不解析** JWT；不接受请求体 / 查询参数里的用户标识 |
| 缺身份头 | 需要登录的接口返回 `401 / 40101` |
| 非法资源访问 | `403 / 40301` |

```powershell
$BASE = "http://localhost:9001"
$UID  = @("-H", "X-User-Id: u-1001")
$ADMIN= @("-H", "X-User-Id: u-admin", "-H", "X-User-Role: ADMIN")
```

> 经网关访问时把 `$BASE` 换成 `http://localhost:8000`，并改用
> `-H "Authorization: Bearer <jwt>"`；网关会自动写入 `X-User-Id` / `X-User-Role`。

### 1.3 状态枚举

| 值 | 含义 |
| --- | --- |
| `DRAFT` | 草稿，仅有元数据，未上传原片 |
| `TRANSCODING` | 原片已上传，转码中 |
| `READY` | 转码完成，可发布 |
| `PUBLISHED` | 已发布，游客可见 |
| `OFFLINE` | 已下架 |
| `FAILED` | 转码失败 |

转码任务状态：`PENDING` / `RUNNING` / `SUCCESS` / `FAILED`

### 1.4 错误码

| HTTP | code | 含义 |
| --- | --- | --- |
| 400 | 40001 | 请求参数不合法 |
| 400 | 60001 | 文件类型不支持 |
| 401 | 40101 | 未认证（缺 `X-User-Id`） |
| 403 | 40301 | 无权限 / 非视频创建者 |
| 404 | 40401 | 视频不存在 |
| 404 | 40402 | 分类不存在 |
| 404 | 40403 | 转码任务不存在 |
| 409 | 40901 | 唯一性冲突（如分类名重复） |
| 409 | 60003 | 视频状态不允许该操作 |
| 413 | 60002 | 文件超出大小限制 |
| 429 | 42901 | 请求过于频繁 |
| 500 | 50000 | 内部错误 |
| 503 | 50001 | 下游依赖不可用（MySQL/Redis/MQ/MinIO） |
| 503 | 60004 | 转码任务提交失败 |

## 2. 健康检查

### 2.1 `GET /healthz` —— 存活探针

不检查任何下游依赖，仅表示进程存活。用于 K8s `livenessProbe`。

```bash
curl.exe http://localhost:9001/healthz
```

```json
{ "code": 0, "message": "success", "data": { "status": "UP", "service": "video-service", "version": "v1.0.0" } }
```

### 2.2 `GET /readyz` —— 就绪探针

逐项检查 MySQL / Redis / 事件总线 / MinIO，任一失败返回 `503 / 50001`。

```bash
curl.exe http://localhost:9001/readyz
```

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "status": "UP",
    "checks": [
      { "name": "mysql",   "status": "UP", "latencyMs": 3,  "detail": "" },
      { "name": "redis",   "status": "UP", "latencyMs": 1,  "detail": "" },
      { "name": "events",  "status": "UP", "latencyMs": 0,  "detail": "driver=rabbitmq" },
      { "name": "minio",   "status": "UP", "latencyMs": 12, "detail": "bucket=media" }
    ]
  }
}
```

## 3. 视频接口

### 3.1 `POST /api/v1/videos` —— 创建视频草稿

| 项 | 值 |
| --- | --- |
| 鉴权 | 必须（`X-User-Id`） |
| Content-Type | `application/json` |

**请求体**

| 字段 | 类型 | 必填 | 约束 |
| --- | --- | --- | --- |
| `title` | string | 是 | 1–128 字符 |
| `description` | string | 否 | ≤ 1024 字符 |
| `categoryId` | int64 | 否 | 需存在，否则 `404 / 40402` |
| `tags` | string[] | 否 | 每个 ≤ 32 字符，最多 10 个 |

```bash
curl.exe -X POST "$BASE/api/v1/videos" @UID `
  -H "Content-Type: application/json" `
  -d '{"title":"Go 并发编程入门","description":"goroutine 与 channel","categoryId":1,"tags":["go","并发"]}'
```

```json
{ "code": 0, "message": "success", "data": { "videoId": 1001, "status": "DRAFT" } }
```

**失败**

| 场景 | 响应 |
| --- | --- |
| 缺 `X-User-Id` | `401 {"code":40101,"message":"未登录或登录已过期","data":null}` |
| `title` 为空 | `400 {"code":40001,"message":"title 不能为空","data":null}` |
| `categoryId` 不存在 | `404 {"code":40402,"message":"分类不存在","data":null}` |

### 3.2 `GET /api/v1/videos` —— 视频列表（分页）

| 项 | 值 |
| --- | --- |
| 鉴权 | 可选（未登录只能看到 `PUBLISHED`） |

**查询参数**

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `page` | int | 1 | 从 1 开始 |
| `pageSize` | int | 20 | 1–100 |
| `keyword` | string | - | 模糊匹配 `title` |
| `categoryId` | int64 | - | 精确匹配 |
| `ownerId` | string | - | 精确匹配创建者 |
| `status` | string | - | 精确匹配状态（**仅创建者本人 / ADMIN 可指定**） |
| `mine` | bool | false | `true` 时只看自己的（等价于 `ownerId=X-User-Id`） |

```bash
curl.exe "$BASE/api/v1/videos?page=1&pageSize=20&keyword=Go" @UID
```

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 1,
    "page": 1,
    "pageSize": 20,
    "items": [
      {
        "id": 1001,
        "title": "Go 并发编程入门",
        "description": "goroutine 与 channel",
        "ownerId": "u-1001",
        "categoryId": 1,
        "categoryName": "编程",
        "tags": ["go", "并发"],
        "coverUrl": "",
        "duration": 0,
        "status": "PUBLISHED",
        "viewCount": 12,
        "publishedAt": "2026-09-27T10:00:00+08:00",
        "createdAt": "2026-09-27T09:00:00+08:00",
        "updatedAt": "2026-09-27T10:00:00+08:00"
      }
    ]
  }
}
```

> **规则**：游客与普通用户请求时，服务端强制附加 `status = PUBLISHED` 条件，
> 即使手工传 `status=DRAFT` 也不会生效（不报错，静默忽略），避免信息泄露。

### 3.3 `GET /api/v1/videos/:id` —— 视频详情

| 项 | 值 |
| --- | --- |
| 鉴权 | 可选 |

```bash
curl.exe "$BASE/api/v1/videos/1001" @UID
```

```json
{
  "code": 0, "message": "success",
  "data": {
    "id": 1001, "title": "Go 并发编程入门", "description": "goroutine 与 channel",
    "ownerId": "u-1001", "categoryId": 1, "categoryName": "编程", "tags": ["go", "并发"],
    "coverUrl": "", "playbackUrl": "http://127.0.0.1:9000/media/video/hls/1001/master.m3u8",
    "duration": 125, "sizeBytes": 10485760, "status": "PUBLISHED", "viewCount": 12,
    "sourceObject": "video/original/1001/source.mp4",
    "publishedAt": "2026-09-27T10:00:00+08:00",
    "createdAt": "2026-09-27T09:00:00+08:00",
    "updatedAt": "2026-09-27T10:00:00+08:00"
  }
}
```

**字段可见性**

| 字段 | 游客 | 所有者 / ADMIN |
| --- | --- | --- |
| `sourceObject` | 不出现在响应中 | 返回 |
| 未发布视频整体 | `404 / 40401` | 正常返回 |

### 3.4 `PUT /api/v1/videos/:id` —— 修改视频

| 项 | 值 |
| --- | --- |
| 鉴权 | 必须，且为创建者 |

**请求体**（全部可选，`null` / 缺省表示「不修改」）

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `title` | string | 1–128 |
| `description` | string | ≤ 1024 |
| `categoryId` | int64 | 需存在 |
| `tags` | string[] | 传数组则**整体替换**，传 `[]` 清空 |

```bash
curl.exe -X PUT "$BASE/api/v1/videos/1001" @UID `
  -H "Content-Type: application/json" `
  -d '{"title":"Go 并发编程入门（第 2 版）","tags":["go","channel","goroutine"]}'
```

```json
{ "code": 0, "message": "success", "data": { "videoId": 1001, "updated": true } }
```

### 3.5 `DELETE /api/v1/videos/:id` —— 删除视频（软删）

| 项 | 值 |
| --- | --- |
| 鉴权 | 必须，且为创建者 |

```bash
curl.exe -X DELETE "$BASE/api/v1/videos/1001" @UID
```

```json
{ "code": 0, "message": "success", "data": { "videoId": 1001, "deleted": true } }
```

> 软删除：对象存储中的文件与 Redis 缓存会在返回前清理，MySQL 行保留 `deleted_at`。

### 3.6 `POST /api/v1/videos/:id/upload` —— 上传原片

| 项 | 值 |
| --- | --- |
| 鉴权 | 必须，且为创建者 |
| Content-Type | `multipart/form-data` |
| 前置状态 | `DRAFT` 或 `FAILED`，否则 `409 / 60003` |

**表单字段**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | file | 是 | 扩展名 ∈ `mp4,mov,mkv,avi,flv,webm`，≤ 2GB |

```bash
curl.exe -X POST "$BASE/api/v1/videos/1001/upload" @UID `
  -F "file=@D:\samples\demo.mp4"
```

```json
{
  "code": 0, "message": "success",
  "data": { "videoId": 1001, "status": "TRANSCODING", "taskId": 9, "sizeBytes": 10485760 }
}
```

**失败**

| 场景 | 响应 |
| --- | --- |
| 扩展名 `exe` | `400 {"code":60001,"message":"不支持的文件类型: exe","data":null}` |
| 超过 2GB | `413 {"code":60002,"message":"文件大小超过限制: 2048MB","data":null}` |
| 状态为 `PUBLISHED` | `409 {"code":60003,"message":"当前状态 PUBLISHED 不允许上传","data":null}` |
| 重复上传（已 `TRANSCODING`） | `200`，返回已有 `taskId`（幂等） |

### 3.7 `POST /api/v1/videos/:id/publish` —— 发布

| 项 | 值 |
| --- | --- |
| 鉴权 | 必须，且为创建者 |
| 前置状态 | `READY` 或 `OFFLINE` |

```bash
curl.exe -X POST "$BASE/api/v1/videos/1001/publish" @UID
```

```json
{ "code": 0, "message": "success", "data": { "videoId": 1001, "status": "PUBLISHED", "publishedAt": "2026-09-27T10:00:00+08:00" } }
```

状态不是 `READY`/`OFFLINE` → `409 / 60003`。

### 3.8 `POST /api/v1/videos/:id/offline` —— 下架

| 项 | 值 |
| --- | --- |
| 鉴权 | 必须，且为创建者 **或 ADMIN** |
| 前置状态 | `PUBLISHED` |

```bash
curl.exe -X POST "$BASE/api/v1/videos/1001/offline" @UID
# 管理员下架他人视频
curl.exe -X POST "$BASE/api/v1/videos/1001/offline" @ADMIN
```

```json
{ "code": 0, "message": "success", "data": { "videoId": 1001, "status": "OFFLINE" } }
```

### 3.9 `GET /api/v1/videos/:id/play` —— 获取播放信息

| 项 | 值 |
| --- | --- |
| 鉴权 | 可选（未发布视频仅所有者 / ADMIN 可访问） |

```bash
curl.exe "$BASE/api/v1/videos/1001/play"
```

```json
{
  "code": 0, "message": "success",
  "data": {
    "videoId": 1001,
    "title": "Go 并发编程入门",
    "coverUrl": "",
    "duration": 125,
    "format": "hls",
    "playbackUrl": "http://127.0.0.1:9000/media/video/hls/1001/master.m3u8",
    "sources": [
      { "profile": "360p",  "url": "http://127.0.0.1:9000/media/video/hls/1001/360p/index.m3u8",  "width": 640,  "height": 360,  "bandwidth": 800000 },
      { "profile": "720p",  "url": "http://127.0.0.1:9000/media/video/hls/1001/720p/index.m3u8",  "width": 1280, "height": 720,  "bandwidth": 2500000 },
```


| 项 | 值 |
| --- | --- |

## 5. 端到端验收脚本

```powershell
$BASE = "http://localhost:9001"
$UID  = "u-1001"

# 0) 健康检查
curl.exe "$BASE/healthz"
curl.exe "$BASE/readyz"

# 1) 创建草稿
$r = curl.exe -s -X POST "$BASE/api/v1/videos" `
  -H "X-User-Id: $UID" -H "Content-Type: application/json" `
  -d '{"title":"Go 并发编程入门","description":"demo","tags":["go"]}' | ConvertFrom-Json
$vid = $r.data.videoId
"videoId = $vid"

# 2) 上传原片（准备一个任意 mp4；mock 转码器不会真正解析内容）
curl.exe -X POST "$BASE/api/v1/videos/$vid/upload" -H "X-User-Id: $UID" -F "file=@D:\samples\demo.mp4"

# 3) 轮询转码（mock 驱动会在数秒内完成）
1..10 | ForEach-Object {
  Start-Sleep -Seconds 2
  $t = curl.exe -s "$BASE/api/v1/videos/$vid/transcode" -H "X-User-Id: $UID" | ConvertFrom-Json
  "task status = $($t.data.status) progress = $($t.data.progress)"
  if ($t.data.status -eq "SUCCESS") { break }
}

# 4) 发布
curl.exe -X POST "$BASE/api/v1/videos/$vid/publish" -H "X-User-Id: $UID"

# 5) 取播放地址（游客身份）
curl.exe "$BASE/api/v1/videos/$vid/play"

# 6) 越权校验：他人修改应 403
curl.exe -X PUT "$BASE/api/v1/videos/$vid" -H "X-User-Id: u-9999" `
  -H "Content-Type: application/json" -d '{"title":"hack"}'
```

> `Start-Sleep` 仅用于演示轮询；真实调用中建议由前端按 `Retry-After` 或固定 2s 间隔轮询。

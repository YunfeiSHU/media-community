# 接口契约约定

> 目的：Java 五个服务 + Go 三个服务对前端只暴露**一套规矩**。
> 前端适配层（`web/src/shared/lib/*`、`entities/*/adapters.ts`）只是兼容现状，不是长期方案；
> 新接口一律按本文执行，存量接口逐步收敛。

---

## 1. 响应信封

所有接口统一：

```json
{ "code": 0, "message": "success", "data": { } }
```

- `code === 0` 表示成功；失败时 `data` 为 `null`（Java 侧配置了 `non_null` 时会省略该字段）。
- 前端必须按 `body.code !== 0` 判失败，不能只看 HTTP 状态：部分业务错误复用 `40001` 但 HTTP 是 409。
- 网关的 401 是手写 JSON（`40101`），429 **没有响应体**——前端不能无条件 `JSON.parse`。

### 错误码段

| 段 | 含义 | 示例 |
| --- | --- | --- |
| `40001` | 参数不合法（HTTP 400） | 字段校验失败 |
| `40101` | 未认证（HTTP 401） | 缺 token / token 过期 |
| `40301` | 无权限（HTTP 403） | 非管理员、非资源所有者 |
| `404xx` | 不存在（HTTP 404） | `40401` 视频、`40404` 上传会话 |
| `409xx` | 状态/唯一性冲突（HTTP 409） | 重复点赞、订单状态不允许 |
| `429xx` | 限流 | 弹幕 `80002` 带 `retryAfterMs` |
| `5xxxx` | 服务内部/依赖不可用 | `50000`、`50001` |
| `6xxxx` | video 域专用 | `60001` 文件类型、`60002` 文件过大 |

**同一个 `code` 在不同域可能语义不同**，判断时要 `HTTP status + code + 当前操作` 一起看。

---

## 2. 时间

**目标**：所有时间字段输出 RFC3339 带偏移，例如 `2026-09-27T10:30:00+08:00`。

现状三种并存（存量）：

| 来源 | 格式 | 时区 |
| --- | --- | --- |
| user / auth | `2026-09-27T10:30:00` | 无偏移（按 Asia/Shanghai 解释） |
| product / order | `2026-09-27 10:30:00` | 无偏移 |
| Go 三服务 | `2026-09-27T10:30:00+08:00` | 带偏移 |

新接口**不得**再输出无偏移格式。前端统一走 `parseServerDate()`，兼容分支在 A4 收敛完成后删除。

---

## 3. 分页

**目标**：

```json
{ "items": [], "total": 24, "page": 1, "pageSize": 12 }
```

存量差异：Java order 侧为 `{page,size,total,list}`，前端在 `adapters.ts` 归一。

| 接口 | pageSize 上限 |
| --- | --- |
| 视频列表 | 100 |
| 直播列表 | 100 |
| 弹幕历史 | 200 |
| 点播历史 | 5000 |
| 批量资料 `uids` | 100 |

超出上限一律 `40001`，不要静默截断。

---

## 4. 空值与可选字段

- 存量：product / order 配置了 `non_null`，空字段**被省略**；user、Go 服务输出 `null`。
- 前端类型一律写可选：`paidAt?: string | null`，判断用 `value == null`（同时覆盖 `undefined` 与 `null`）。
- 新接口统一输出 `null`，不做字段省略——省略会让「字段不存在」和「旧版本后端」无法区分。

---

## 5. ID 语义

| 字段 | 含义 |
| --- | --- |
| `id`（商品/订单/SKU） | 内部自增主键 |
| `productId` / `orderId` / `skuId` | 对外业务编号（`P...` / `O...` / `S...`） |
| `id`（视频）/ `roomId` | 主键，同时也是对外 ID |
| `danmaku.roomId` / `videoId` | **字符串** |
| `uid` | 字符串，对客身份 |

前端不要定义通用 `id: number`，按实体分别声明；视频 ID 统一转 `string`。

---

## 6. 枚举

| 领域 | 风格 |
| --- | --- |
| 视频/直播 `status` | 字符串（`PUBLISHED` / `LIVING`） |
| 用户 `status` | 字符串（`NORMAL` / `DISABLED`） |
| 弹幕 `position` | 字符串（`SCROLL` / `TOP` / `BOTTOM`） |
| 商品 `status` / `productType` | 数字（S3 阶段补 `statusName`） |
| 订单 / 支付 `status` | 数字 + `statusName` |

新接口优先用字符串 + 可选 `xxxName`；前端对未知值必须有兜底文案。

---

## 7. 金额

统一用**分**（`Long`）。展示在 `shared/lib/money.ts` 里做，禁止在 JS 里把分转成元再做加减。

---

## 8. 鉴权与身份

- 客户端只带 `Authorization: Bearer <access>`；网关注入 `X-User-Id`（JWT `sub`）与 `X-User-Role`。
- 下游服务**只信任这两个头**，不解析 JWT，也不接受请求体/查询参数里的用户标识。
- 三类路径：
  - `permit-all`：匿名可访问，**身份头被剥离**；
  - `optional-auth`：有令牌才注入身份，无令牌按游客放行，坏令牌 401；
  - 默认：必须登录。
- 需要「游客可看、登录后看自己的」接口（`?mine=true`、`?favorite=true`、点赞状态）**必须放 optional-auth**，放 permit-all 会导致身份永远为空。

---

## 9. 媒体地址

- 前端只认相对路径：`/media/...`、`/live/...`，由 Nginx 反代到 MinIO / SRS。
- 服务端返回的绝对地址必须跟随外部协议（HTTPS 页面不能返回 `http://`），且不能是 `localhost`。
- `.m3u8` 不缓存；`.ts`、图片长缓存。

---

## 10. 变更流程

1. 改字段先改本文 + 对应服务 `docs/接口文档.md`；
2. 同步网关白名单 / `optional-auth`（最容易漏，表现为「直连能通、走网关 401」）；
3. 前端 `entities/*/api.ts` 与 mock 数据同步更新；
4. 新增公开接口必须在网关测试里加一条「无令牌可访问」用例。

### HTTP

| 功能     | 方法 | 接口                               | 归属要求   |
| -------- | ---- | ---------------------------------- | ---------- |
| 创建商品 | POST | `/api/v1/products`                 | 登录       |
| 商品详情 | GET  | `/api/v1/products/{id}`            | 公开       |
| 修改商品 | PUT  | `/api/v1/products/{id}`            | 仅创建者   |
| 上架     | POST | `/api/v1/products/{id}/on-shelf`   | 仅创建者   |
| 下架     | POST | `/api/v1/products/{id}/off-shelf`  | 仅创建者   |
| 创建 SKU | POST | `/api/v1/products/{id}/skus`       | 仅创建者   |
| SKU详情  | GET  | `/api/v1/skus/{id}`                | 公开       |
| 修改 SKU | PUT  | `/api/v1/skus/{id}`                | 仅创建者   |
| 修改价格 | PUT  | `/api/v1/skus/{id}/price`          | 仅创建者   |
| 查询库存 | GET  | `/api/v1/skus/{id}/stock`          | 公开       |
| 增加库存 | POST | `/api/v1/skus/{id}/stock/increase` | 仅创建者   |

> 身份约定：写接口都要求登录，当前用户只从网关注入的 `X-User-Id`（= JWT 标准 claim `sub`）读取，
> 由 `com.example.product.common.CurrentUser` 统一解析；**创建商品不再接受请求体里的 `uid`**，
> 缺身份头返回 `401 / 40101`。服务本身不解析 JWT（鉴权只发生在 gateway-service）。
>
> 角色同理：只能读网关注入的 `X-User-Role`（= JWT 的 `role` claim），入口是 `CurrentUser.role()` /
> `CurrentUser.requireAdmin()`（角色不足 → `403 / 40301`），不得自行解析 JWT 或采信客户端自报的角色。
>
> 归属校验：“仅创建者” = `product.uid` 必须等于 `X-User-Id`，统一由
> `com.example.product.support.ProductOwnership` 判定，不匹配抛 `BizException(ErrorCode.FORBIDDEN)`
> → `403 / 40301`（`无权操作他人商品: P…`）。SKU / 价格 / 库存的归属按所属商品判断。
> 只读查询保持公开（商品与 SKU 详情本身可被任何人浏览）；
> Dubbo 的 `ProductRpcService` / `StockRpcService` 服务于订单交易链路、没有用户上下文，**不做归属校验**。
> 角色不等同于归属：即使是 `ADMIN`，也要是该商品的创建者才能写。

### 表设计：

```
product:商品本身是什么，以及这个商品属于谁。
   │
   │ 1 : N
   ↓
 sku:商品具体卖什么规格，以及具体售价。
   │
   │ 1 : 1
   ↓
inventory:SKU 当前有多少可用库存，以及多少库存已经被订单预占。
```

```sql
CREATE TABLE product (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '商品内部ID',

    product_id VARCHAR(32) NOT NULL COMMENT '商品业务编号',

    uid VARCHAR(32) NOT NULL COMMENT '商品创建者UID',

    name VARCHAR(128) NOT NULL COMMENT '商品名称',

    description VARCHAR(500) DEFAULT NULL COMMENT '商品描述',

    cover_url VARCHAR(512) DEFAULT NULL COMMENT '商品封面',

    product_type TINYINT NOT NULL COMMENT '商品类型',

    status TINYINT NOT NULL DEFAULT 0 COMMENT '商品状态',

    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,

    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
        ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_product_no (product_no),

    KEY idx_uid_status (uid, status),

    KEY idx_type_status (product_type, status)
) ENGINE=InnoDB
  DEFAULT CHARSET=utf8mb4
  COMMENT='商品表';
```

```sql
CREATE TABLE sku (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT 'SKU内部ID',

    sku_id VARCHAR(32) NOT NULL COMMENT 'SKU业务编号',

    product_id BIGINT NOT NULL COMMENT '所属商品ID',

    name VARCHAR(128) NOT NULL COMMENT 'SKU名称',

    price BIGINT NOT NULL COMMENT '售价，单位：分',

    status TINYINT NOT NULL DEFAULT 1 COMMENT 'SKU状态',

    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,

    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
        ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_sku_no (sku_no),

    KEY idx_product_id (product_id),

    KEY idx_product_status (product_id, status)
) ENGINE=InnoDB
  DEFAULT CHARSET=utf8mb4
  COMMENT='商品SKU表';
```

```sql
CREATE TABLE inventory (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '库存记录ID',

    sku_id BIGINT NOT NULL COMMENT 'SKU ID',

    available_stock INT NOT NULL DEFAULT 0 COMMENT '可用库存',

    locked_stock INT NOT NULL DEFAULT 0 COMMENT '已锁定库存',

    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,

    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
        ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_sku_id (sku_id)
) ENGINE=InnoDB
  DEFAULT CHARSET=utf8mb4
  COMMENT='SKU库存表';
```

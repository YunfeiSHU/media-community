# danmaku-service-go · 接口文档

> 服务端口：**9003** ｜ HTTP 基础路径：`/api/v1` ｜ WebSocket：`/ws/danmaku`
> 健康检查：`/healthz`、`/readyz` ｜ 契约定稿：v1.0（阶段一）

---

## 1. 通用约定

### 1.1 统一响应体（HTTP）

```json
{ "code": 0, "message": "success", "data": { } }
```

### 1.2 身份传递

| 项 | 约定 |
| --- | --- |
| HTTP uid 来源 | 请求头 `X-User-Id` |
| 角色来源 | 请求头 `X-User-Role`（`ADMIN` / `user`） |
| WebSocket uid 来源 | query 参数 `uid`（浏览器 WS 无法自定义头）；生产环境由网关注入 |
| 游客 | HTTP 可读历史；**不可发送**；WS 可连接但只收不发 |
| 缺身份头发送 | `401 / 40101` |

```powershell
$BASE = "http://localhost:9003"
$U1   = @("-H", "X-User-Id: u-2001", "-H", "X-User-Role: user")
$ADM  = @("-H", "X-User-Id: u-admin", "-H", "X-User-Role: ADMIN")
```

### 1.3 枚举

| 字段 | 取值 | 默认 |
| --- | --- | --- |
| `position` | `SCROLL` / `TOP` / `BOTTOM` | `SCROLL` |
| `color` | `#RRGGBB` 或 `#AARRGGBB`（十六进制） | `#FFFFFF` |
| `status` | `NORMAL` / `RECALLED` | `NORMAL` |

### 1.4 错误码

| HTTP | code | 含义 |
| --- | --- | --- |
| 400 | 40001 | 请求参数不合法（空内容 / 超长 / 颜色格式错误） |
| 400 | 80001 | 弹幕内容不合法（命中敏感词） |
| 401 | 40101 | 未认证（发送弹幕需要登录） |
| 403 | 40301 | 无权限（撤回他人弹幕） |
| 404 | 40401 | 弹幕不存在 |
| 409 | 80003 | 直播间当前未开播，不允许发送弹幕 |
| 429 | 42901 / 80002 | 发送过于频繁（带 `retryAfterMs`） |
| 500 | 50000 | 内部错误 |
| 503 | 50001 | 下游依赖不可用 |

### 2.2 `GET /readyz`

```json
{
  "code": 0, "message": "success",
  "data": {
    "status": "UP",
    "checks": [
      { "name": "mysql",  "status": "UP", "latencyMs": 2, "detail": "ok" },
```

## 3. 弹幕发送

### 3.1 `POST /api/v1/danmaku/send` —— 发送弹幕

| 项 | 值 |
| --- | --- |
| 鉴权 | 必须（`X-User-Id`） |
| Content-Type | `application/json` |

**请求体**

| 字段 | 类型 | 必填 | 约束 |
| --- | --- | --- | --- |
| `roomId` | string | 二选一 | 直播房间 ID（直播弹幕） |
| `videoId` | string | 二选一 | 视频 ID（点播弹幕） |
| `content` | string | 是 | 1–100 字符（去首尾空白后） |
| `color` | string | 否 | `#RRGGBB` / `#AARRGGBB`，默认 `#FFFFFF` |
| `position` | string | 否 | `SCROLL` / `TOP` / `BOTTOM`，默认 `SCROLL` |
| `timeMs` | int | 点播必填 | 视频时间轴位置（毫秒），直播填写 0 |
| `clientMsgId` | string | 否 | 客户端幂等键（建议 UUID）；10s 内重复提交视为同一条 |
| `nickname` | string | 否 | 展示昵称 |

> **禁止字段**：请求体中的 `uid` 会被忽略（身份只来自 `X-User-Id`）。

**直播弹幕**

```bash
curl.exe -X POST "$BASE/api/v1/danmaku/send" @U1 `
  -H "Content-Type: application/json" `
  -d '{"roomId":"5001","content":"好耶","color":"#FFFFFF","position":"SCROLL","clientMsgId":"c-0001"}'
```

```json
{
  "code": 0, "message": "success",
  "data": {
    "danmakuId": 0,
    "clientMsgId": "c-0001",
    "roomId": "5001",
    "videoId": "",
    "uid": "u-2001",
    "nickname": "u-2001",
    "content": "好耶",
    "color": "#FFFFFF",
    "position": "SCROLL",
    "timeMs": 0,
    "sentAt": "2026-09-27T20:00:01.123+08:00",
    "status": "NORMAL",
    "persisted": true
  }
}
```

> `danmakuId` 为 `0` 表示**尚未落库**（ID 由 MySQL 自增生成，异步写入）。
> `persisted:false` 表示 MQ 投递失败，已进入 Redis 补发队列（客户端无需处理，
> 但可用于监控告警）。这种「广播不等落库」的设计意味着**不能**用 `danmakuId`
> 作为广播链路的标识 —— 请使用 `clientMsgId` + `sentAt`。

**点播弹幕**

```bash
curl.exe -X POST "$BASE/api/v1/danmaku/send" @U1 `
  -H "Content-Type: application/json" `
  -d '{"videoId":"1001","content":"这里是重点","timeMs":15000,"color":"#FF0000","position":"TOP"}'
```

**失败**

| 场景 | 响应 |
| --- | --- |
| 未登录 | `401 {"code":40101,"message":"未登录或登录已过期","data":null}` |
| 内容为空 | `400 {"code":40001,"message":"content 不能为空","data":null}` |
| 内容 101 字 | `400 {"code":40001,"message":"content 长度不能超过 100 个字符","data":null}` |
| 颜色格式错 | `400 {"code":40001,"message":"color 必须是 #RRGGBB 格式","data":null}` |
| 命中敏感词 | `400 {"code":80001,"message":"弹幕包含违规内容","data":null}` |
| 房间未开播 | `409 {"code":80003,"message":"直播间当前未开播","data":null}` |
| 1 秒内第 6 条 | `429 {"code":80002,"message":"发送过于频繁","data":{"retryAfterMs":640}}` |
| 房间限流触发 | `429 {"code":80002,"message":"当前直播间弹幕过多，请稍后再试","data":{"retryAfterMs":210}}` |

### 3.2 WebSocket 发送

见 §6。协议帧 `{"type":"danmaku","data":{...}}`，字段与 HTTP 请求体一致，
错误通过 `error` 帧返回（不关闭连接）。

### 3.3 `DELETE /api/v1/danmaku/:danmakuId` —— 撤回弹幕

| 项 | 值 |
| --- | --- |
| 鉴权 | 必须；仅发送者本人 或 ADMIN |
| 时间窗 | 发送后 120s 内（可配置；`0` 表示不限制） |

```bash
curl.exe -X DELETE "$BASE/api/v1/danmaku/1024" @U1
```

```json
{ "code": 0, "message": "success", "data": { "danmakuId": 1024, "status": "RECALLED", "recalledAt": "2026-09-27T20:02:00+08:00" } }
```

**失败**

| 场景 | 响应 |
| --- | --- |
| 弹幕不存在 | `404 {"code":40401,"message":"弹幕不存在","data":null}` |
| 撤回他人弹幕 | `403 {"code":40301,"message":"只能撤回自己发送的弹幕","data":null}` |
| 超过时间窗 | `409 {"code":40001,"message":"超过可撤回时间窗(120s)","data":null}` |

> 撤回后：MySQL `status=RECALLED`；若弹幕仍在 Redis 热数据中，同步移除。
> 撤回不广播（客户端下次拉取历史时消失）——直播场景下撤回一条已投屏的弹幕
> 会造成视觉跳跃，产品上选择「静默撤回」。

## 4. 历史查询

### 4.1 `GET /api/v1/danmaku/rooms/:roomId/history` —— 直播弹幕历史

| 项 | 值 |
| --- | --- |
| 鉴权 | 无（公开） |
| 排序 | 按 `sentAt` **倒序**（最新在前） |

**查询参数**

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `page` | int | 1 | 从 1 开始 |
| `pageSize` | int | 50 | 1–200 |
| `source` | string | auto | `auto` / `hot` / `db`：`auto` 表示第 1 页走 Redis 热数据 |

```bash
curl.exe "$BASE/api/v1/danmaku/rooms/5001/history?page=1&pageSize=50"
```

```json
{
  "code": 0, "message": "success",
  "data": {
    "total": 3421,
    "page": 1,
    "pageSize": 50,
    "source": "hot",
    "items": [
      {
        "danmakuId": 1024,
        "clientMsgId": "c-0001",
        "roomId": "5001",
        "videoId": "",
        "uid": "u-2001",
        "nickname": "u-2001",
        "content": "好耶",
        "color": "#FFFFFF",
        "position": "SCROLL",
        "timeMs": 0,
        "sentAt": "2026-09-27T20:00:01.123+08:00",
        "status": "NORMAL"
      }
    ]
  }
}
```

> `total` 在 `source=hot` 时为**该房间累计弹幕数**（MySQL 计数），
> 而不是热数据条数，避免前端分页器显示错误的总页数。

### 4.2 `GET /api/v1/danmaku/videos/:videoId/history` —— 点播弹幕历史

| 项 | 值 |
| --- | --- |
| 鉴权 | 无 |
| 排序 | 按 `timeMs` **升序**（供播放器按时间轴投放） |

**查询参数**

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `fromMs` | int | 0 | 起始时间（含） |
| `toMs` | int | 0 | 结束时间（含）；`0` 表示不限 |
| `limit` | int | 2000 | 1–5000（硬上限） |

```bash
curl.exe "$BASE/api/v1/danmaku/videos/1001/history?fromMs=0&toMs=30000&limit=2000"
```

```json
{
  "code": 0, "message": "success",
  "data": {
    "videoId": "1001",
    "fromMs": 0,
    "toMs": 30000,
    "count": 2,
    "items": [
      { "danmakuId": 2001, "timeMs": 1500, "content": "开场了", "color": "#FFFFFF", "position": "SCROLL", "uid": "u-2001", "sentAt": "2026-09-20T10:00:00+08:00", "status": "NORMAL" },
      { "danmakuId": 2002, "timeMs": 15000, "content": "这里是重点", "color": "#FF0000", "position": "TOP", "uid": "u-3001", "sentAt": "2026-09-20T10:05:00+08:00", "status": "NORMAL" }
    ]
  }
}
```

> 单次查询硬上限 5000 条：超过说明数据异常或遭受攻击，宁可截断（并在响应头
> `X-Result-Truncated: true` 标注）也不让单个请求拖垮服务。

### 5.3 `POST /api/v1/danmaku/admin/words` —— 新增敏感词

| 项 | 值 |
| --- | --- |
| 鉴权 | 必须，ADMIN |

```bash
curl.exe -X POST "$BASE/api/v1/danmaku/admin/words" @ADM `
  -H "Content-Type: application/json" -d '{"word":"新词","strategy":"REJECT"}'
```

```json
{ "code": 0, "message": "success", "data": { "id": 3, "word": "新词", "strategy": "REJECT", "enabled": true } }
```

> 新增后**自动触发一次热重载**，无需手动调用 `reload-words`。
> 词已存在 → `409 {"code":40901,"message":"敏感词已存在: 新词","data":null}`

## 6. WebSocket 协议

### 6.1 连接

```text
ws://localhost:9003/ws/danmaku?roomId=5001&uid=u-2001&nickname=小明
ws://localhost:9003/ws/danmaku?videoId=1001
```

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `roomId` | 二选一 | 直播房间 ID |
| `videoId` | 二选一 | 点播视频 ID |
| `uid` | 否 | 为空即游客（只读） |
| `nickname` | 否 | 展示昵称 |

**握手成功 → 服务端首帧**

```json
{ "type": "welcome", "data": { "clientId": "c-8f2a1b", "roomId": "5001", "uid": "u-2001", "readOnly": false, "onlineCount": 128, "hotCount": 500, "serverTime": "2026-09-27T20:00:00+08:00" } }
```

**握手失败**（HTTP 400 / 403，不升级连接）

```json
{ "code": 40001, "message": "必须提供 roomId 或 videoId", "data": null }
{ "code": 80003, "message": "直播间当前未开播", "data": null }
```

### 6.2 客户端 → 服务端

**发送弹幕**

```json
{ "type": "danmaku", "data": { "content": "好耶", "color": "#FFFFFF", "position": "SCROLL", "timeMs": 0, "clientMsgId": "c-0002" } }
```

> `roomId` / `videoId` 以握手参数为准，**帧内无需重复传**（防止跨房间注入）。

**心跳**

```json
{ "type": "ping", "data": {} }
```

### 6.3 服务端 → 客户端

**弹幕广播**

```json
{ "type": "danmaku", "data": { "danmakuId": 0, "clientMsgId": "c-0002", "roomId": "5001", "videoId": "", "uid": "u-2001", "nickname": "u-2001", "content": "好耶", "color": "#FFFFFF", "position": "SCROLL", "timeMs": 0, "sentAt": "2026-09-27T20:00:02.001+08:00", "status": "NORMAL" } }
```

**心跳响应**

```json
{ "type": "pong", "data": { "serverTime": "2026-09-27T20:00:30+08:00" } }
```

**系统消息**

```json
{ "type": "system", "data": { "event": "LIVE_STARTED", "message": "直播已开始", "at": "2026-09-27T20:00:00+08:00" } }
{ "type": "system", "data": { "event": "LIVE_ENDED",   "message": "直播已结束", "at": "2026-09-27T22:31:05+08:00" } }
```

**错误**

```json
{ "type": "error", "data": { "code": 80002, "message": "发送过于频繁", "retryAfterMs": 640 } }
{ "type": "error", "data": { "code": 80001, "message": "弹幕包含违规内容" } }
```

### 6.4 连接生命周期

| 事件 | 行为 |
| --- | --- |
| 连接建立 | 注册到房间 Hub，回 `welcome` |
| 客户端 30s 未发 ping | 服务端发 WebSocket Ping 帧探测 |
| 60s 未收到 Pong | 关闭连接（`close` 1001） |
| 同一 uid 第 4 条连接 | 关闭该 uid 最旧的连接（`close` 4001「在其他地方打开」） |
| 连续 3 次协议解析失败 | 关闭连接（`close` 1003） |
| 服务端优雅退出 | 广播 `system: SERVER_SHUTDOWN` 后关闭 |

**客户端示例（JavaScript）**

```javascript
const ws = new WebSocket("ws://localhost:9003/ws/danmaku?roomId=5001&uid=u-2001&nickname=小明");

ws.onmessage = (e) => {
  const frame = JSON.parse(e.data);
  switch (frame.type) {
    case "welcome": console.log("已连接", frame.data); break;
    case "danmaku": render(frame.data); break;
    case "system":  console.log("系统消息", frame.data); break;
    case "error":   console.warn("发送失败", frame.data); break;
  }
};

// 发送弹幕
ws.send(JSON.stringify({ type: "danmaku", data: { content: "好耶", clientMsgId: crypto.randomUUID() } }));

// 心跳
setInterval(() => ws.send(JSON.stringify({ type: "ping", data: {} })), 30000);
```

## 7. 端到端验收脚本

```powershell
$BASE = "http://localhost:9003"
$U1 = "u-2001"; $U2 = "u-3001"

# 0) 健康检查（确认 filter 已加载词库）
curl.exe "$BASE/healthz"
curl.exe "$BASE/readyz"

# 1) 游客发送应 401
curl.exe -X POST "$BASE/api/v1/danmaku/send" -H "Content-Type: application/json" `
  -d '{"roomId":"5001","content":"游客弹幕"}'

# 2) 正常发送
curl.exe -X POST "$BASE/api/v1/danmaku/send" -H "X-User-Id: $U1" `
  -H "Content-Type: application/json" `
  -d '{"roomId":"5001","content":"第一条弹幕","clientMsgId":"acc-001"}'

# 3) 敏感词（先在 §5.3 用 ADMIN 新增一个词）
curl.exe -X POST "$BASE/api/v1/danmaku/send" -H "X-User-Id: $U1" `
  -H "Content-Type: application/json" -d '{"roomId":"5001","content":"这里含敏感词"}'

# 4) 幂等：同一 clientMsgId 重复提交，只应产生一条
curl.exe -X POST "$BASE/api/v1/danmaku/send" -H "X-User-Id: $U1" `
  -H "Content-Type: application/json" `
  -d '{"roomId":"5001","content":"第一条弹幕","clientMsgId":"acc-001"}'

# 5) 限流：1 秒内连发 7 条，最后应出现 80002
1..7 | ForEach-Object {
  curl.exe -s -X POST "$BASE/api/v1/danmaku/send" -H "X-User-Id: $U1" `
    -H "Content-Type: application/json" -d "{`"roomId`":`"5001`",`"content`":`"刷屏 $_`"}"
}

# 6) 历史（第 1 页走 Redis 热数据）
curl.exe "$BASE/api/v1/danmaku/rooms/5001/history?page=1&pageSize=50"
curl.exe "$BASE/api/v1/danmaku/stats?roomId=5001"

# 7) 点播弹幕
curl.exe -X POST "$BASE/api/v1/danmaku/send" -H "X-User-Id: $U2" `
  -H "Content-Type: application/json" `
  -d '{"videoId":"1001","content":"这里是重点","timeMs":15000,"position":"TOP","color":"#FF0000"}'
curl.exe "$BASE/api/v1/danmaku/videos/1001/history?fromMs=0&toMs=30000"

# 8) 撤回：他人撤回应 403，本人撤回应 200
curl.exe -X DELETE "$BASE/api/v1/danmaku/1" -H "X-User-Id: u-9999"
curl.exe -X DELETE "$BASE/api/v1/danmaku/1" -H "X-User-Id: $U1"
```

**WebSocket 验证（浏览器控制台）**

```javascript
// 开两个标签页，都执行下面这段（第二个用 uid=u-3001）
const uid = "u-2001";
const ws = new WebSocket(`ws://localhost:9003/ws/danmaku?roomId=5001&uid=${uid}`);
ws.onmessage = e => {
  const f = JSON.parse(e.data);
  if (f.type === "danmaku") console.log("[收到弹幕]", f.data.content, "from", f.data.uid);
  if (f.type === "welcome") console.log("[欢迎]", f.data);
};
// 在标签页 1 发送：另一个标签页应立刻打印 [收到弹幕]
setTimeout(() => ws.send(JSON.stringify({type:"danmaku",data:{content:"跨连接测试",clientMsgId:crypto.randomUUID()}})), 2000);
```

**点播弹幕渲染（示意）**

```javascript
const danmakus = (await (await fetch("http://localhost:9003/api/v1/danmaku/videos/1001/history?fromMs=0&toMs=600000")).json()).data.items;
const video = document.querySelector("video");
let cursor = 0;
video.addEventListener("timeupdate", () => {
  const nowMs = video.currentTime * 1000;
  while (cursor < danmakus.length && danmakus[cursor].timeMs <= nowMs) {
    renderToScreen(danmakus[cursor++]);   // 按 timeMs 升序投放
  }
});
```

## 8. 与另外两个服务的衔接

| 依赖 | 方向 | 方式 |
| --- | --- | --- |
| `live-service-go` | 订阅 | 消费 `live.started`（激活房间、清空上一轮热数据）与 `live.stopped`（广播结束消息、最后一次落库） |
| `live-service-go` | 调用 | 需要「房间是否存在 / 是否直播中」时：优先用本地 Redis `danmaku:live:{roomId}`（由事件维护）；缓存缺失时回退调 `GET http://localhost:9002/api/v1/live/rooms/{id}/online` |
| `video-service-go` | 调用 | 点播弹幕发送前校验视频存在与可见性（阶段一仅记录，不强制校验，避免强耦合） |
| Java 网关 | 被调用 | `/api/v1/danmaku/**` 走网关（需 JWT）；`/ws/danmaku` 需要网关支持 WebSocket 透传 |

**事件消费契约**

```text
live.started → payload: { roomId, ownerId, sessionId, title, coverUrl, startedAt }
   本服务动作：
     1. SET danmaku:live:{roomId} = 1
     2. DEL danmaku:room:{roomId}:recent（清理上一轮）
     3. 若该房间有活跃连接，广播 system: LIVE_STARTED

live.stopped → payload: { roomId, sessionId, endedAt, durationSec, peakOnline, viewerTotal, reason }
   本服务动作：
     1. DEL danmaku:live:{roomId}
     2. 广播 system: LIVE_ENDED
     3. 触发一次「热数据 → MySQL」补落库（防止 MQ 曾抖动导致丢数据）
```

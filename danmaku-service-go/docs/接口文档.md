# danmaku-service-go · 接口文档

> 服务端口：**9003** ｜ HTTP 基础路径：`/api/v1` ｜ WebSocket：`/ws/danmaku` ｜ 探针：`/healthz`、`/readyz`
> 设计取舍与验收标准见 [`设计文档.md`](设计文档.md)；仓库总览见 [`../README.md`](../../README.md)

## 1. 通用约定

| 项 | 约定 |
| --- | --- |
| 响应体 | `{ code, message, data }`，`code=0` 成功（信封规范见 [`../README.md` §5.1](../../README.md)） |
| HTTP uid / 角色 | 请求头 `X-User-Id` / `X-User-Role`（`ADMIN` / `user`），由网关注入，请求体 `uid` 一律忽略 |
| WebSocket uid | query 参数 `uid`（浏览器 WS 无法自定义头）；为空即游客，只收不发 |
| 游客 | 可连 WS、可查历史；**不可发送**（`401 / 40101`） |
| 错误码 | 本服务专用码见 [`设计文档.md` §11](设计文档.md)，跨服务总表见 [`../README.md` §5.3](../../README.md) |

| 字段 | 取值 | 默认 |
| --- | --- | --- |
| `position` | `SCROLL` / `TOP` / `BOTTOM` | `SCROLL` |
| `color` | `#RRGGBB` 或 `#AARRGGBB` | `#FFFFFF` |
| `status` | `NORMAL` / `RECALLED` | `NORMAL` |

```powershell
$BASE = "http://localhost:9003"
$U1   = @("-H", "X-User-Id: u-2001", "-H", "X-User-Role: user")
$ADM  = @("-H", "X-User-Id: u-admin", "-H", "X-User-Role: ADMIN")
```

## 2. 健康检查

`GET /healthz`：

```json
{ "code": 0, "message": "success", "data": { "status": "UP", "service": "danmaku-service", "version": "v1.0.0" } }
```

`GET /readyz`：

```json
{ "code": 0, "message": "success", "data": { "status": "UP", "checks": [
  { "name": "mysql",  "status": "UP", "latencyMs": 2, "detail": "ok" },
  { "name": "redis",  "status": "UP", "latencyMs": 1, "detail": "ok" },
  { "name": "events", "status": "UP", "latencyMs": 0, "detail": "driver=rabbitmq" },
  { "name": "filter", "status": "UP", "latencyMs": 0, "detail": "words=7 strategy=REJECT" } ] } }
```

> `filter.detail` 给出**已加载的敏感词数量**，是排查「敏感词没生效」最直接的手段（`words=0` 即词库为空）。

## 3. 弹幕发送

### 3.1 `POST /api/v1/danmaku/send`

鉴权必须（`X-User-Id`），`Content-Type: application/json`。`roomId` 也可放在路径里：`POST /api/v1/danmaku/rooms/:roomId/send`。

| 字段 | 类型 | 必填 | 约束 |
| --- | --- | --- | --- |
| `roomId` | string | 二选一 | 直播房间 ID |
| `videoId` | string | 二选一 | 点播视频 ID |
| `content` | string | 是 | 1–100 字符（去首尾空白后） |
| `color` | string | 否 | `#RRGGBB` / `#AARRGGBB`，默认 `#FFFFFF` |
| `position` | string | 否 | `SCROLL` / `TOP` / `BOTTOM`，默认 `SCROLL` |
| `timeMs` | int | 点播必填 | 视频时间轴位置（毫秒），直播填 0 |
| `clientMsgId` | string | 否 | 客户端幂等键（建议 UUID）；10s 内重复提交视为同一条 |
| `nickname` | string | 否 | 展示昵称 |

**直播弹幕**

```powershell
curl.exe -X POST "$BASE/api/v1/danmaku/send" @U1 -H "Content-Type: application/json" `
  -d '{"roomId":"5001","content":"好耶","color":"#FFFFFF","position":"SCROLL","clientMsgId":"c-0001"}'
```

```json
{ "code": 0, "message": "success", "data": {
  "danmakuId": 0, "clientMsgId": "c-0001", "roomId": "5001", "videoId": "",
  "uid": "u-2001", "nickname": "u-2001", "content": "好耶", "color": "#FFFFFF",
  "position": "SCROLL", "timeMs": 0, "sentAt": "2026-09-27T20:00:01.123+08:00",
  "status": "NORMAL", "persisted": true } }
```

> `danmakuId` 为 `0` 表示**尚未落库**（ID 由 MySQL 自增生成，异步写入）；`persisted:false` 表示 MQ 投递失败、
> 已进 Redis 补发队列。因此广播链路**不能**用 `danmakuId` 作标识，请用 `clientMsgId` + `sentAt`。

**点播弹幕**

```powershell
curl.exe -X POST "$BASE/api/v1/danmaku/send" @U1 -H "Content-Type: application/json" `
  -d '{"videoId":"1001","content":"这里是重点","timeMs":15000,"color":"#FF0000","position":"TOP"}'
```

**失败响应**

| 场景 | 响应 |
| --- | --- |
| 未登录 | `401 {"code":40101,"message":"未登录或登录已过期","data":null}` |
| 内容为空 | `400 {"code":40001,"message":"content 不能为空","data":null}` |
| 内容 101 字 | `400 {"code":40001,"message":"content 长度不能超过 100 个字符","data":null}` |
| 颜色格式错 | `400 {"code":40001,"message":"color 必须是 #RRGGBB 格式","data":null}` |
| `roomId` / `videoId` 未二选一 | `400 {"code":40001,"message":"roomId 与 videoId 必须二选一","data":null}` |
| 命中敏感词 | `400 {"code":80001,"message":"弹幕包含违规内容","data":null}` |
| 房间未开播 | `409 {"code":80003,"message":"直播间当前未开播","data":null}` |
| 用户级限流（1 秒第 6 条） | `429 {"code":80002,"message":"发送过于频繁","data":{"retryAfterMs":640}}` |
| 房间级限流 | `429 {"code":80002,"message":"当前直播间弹幕过多，请稍后再试","data":{"retryAfterMs":210}}` |

> 幂等语义：同一 `clientMsgId` 在 10s 内重复提交返回**首发结果快照**（同一条 `sentAt` / `clientMsgId`），
> 不新增弹幕；`retryAfterMs` 是当前窗口的剩余毫秒，客户端应据此退避而不是立即重试。

### 3.2 WebSocket 发送

见 §6。帧 `{"type":"danmaku","data":{...}}`，字段与 HTTP 请求体一致（`roomId`/`videoId` 以握手参数为准），错误走 `error` 帧、不关闭连接。

### 3.3 `DELETE /api/v1/danmaku/:danmakuId` —— 撤回

鉴权必须；仅发送者本人或 `ADMIN`；时间窗发送后 **120s** 内（`recall_window`，`0` 表示不限制）。

```powershell
curl.exe -X DELETE "$BASE/api/v1/danmaku/1024" @U1
```

```json
{ "code": 0, "message": "success", "data": { "danmakuId": 1024, "status": "RECALLED", "recalledAt": "2026-09-27T20:02:00+08:00" } }
```

| 场景 | 响应 |
| --- | --- |
| 弹幕不存在 | `404 {"code":40401,"message":"弹幕不存在","data":null}` |
| 撤回他人弹幕 | `403 {"code":40301,"message":"只能撤回自己发送的弹幕","data":null}` |
| 超过时间窗 | `409 {"code":40001,"message":"超过可撤回时间窗(120s)","data":null}` |

> 撤回后 MySQL `status=RECALLED`，Redis 热数据中的同 `clientMsgId` 条目同步 `LREM`。
> 撤回**不广播**——抹掉已投屏的弹幕会造成视觉跳跃，客户端下次拉历史时消失。

## 4. 历史查询

### 4.1 `GET /api/v1/danmaku/rooms/:roomId/history` —— 直播历史

无需鉴权；按 `sentAt` **倒序**。

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `page` | int | 1 | 从 1 开始 |
| `pageSize` | int | 50 | 1–200 |
| `source` | string | `auto` | `auto` / `hot` / `db`；`auto` 表示第 1 页走 Redis 热数据 |

```powershell
curl.exe "$BASE/api/v1/danmaku/rooms/5001/history?page=1&pageSize=50"
```

```json
{ "code": 0, "message": "success", "data": {
  "total": 3421, "page": 1, "pageSize": 50, "source": "hot",
  "items": [ { "danmakuId": 1024, "clientMsgId": "c-0001", "roomId": "5001", "videoId": "",
    "uid": "u-2001", "nickname": "u-2001", "content": "好耶", "color": "#FFFFFF",
    "position": "SCROLL", "timeMs": 0, "sentAt": "2026-09-27T20:00:01.123+08:00",
    "status": "NORMAL" } ] } }
```

> `total` 在 `source=hot` 时是**该房间累计弹幕数**（MySQL 计数），不是热数据条数，避免前端分页器算错总页数。
> `source=auto` 的判定：`page=1` 且 `pageSize ≤ 500`（热数据条数上限）走 Redis List，否则读 MySQL。

### 4.2 `GET /api/v1/danmaku/videos/:videoId/history` —— 点播历史

无需鉴权；按 `timeMs` **升序**（供播放器按时间轴投放）。

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `fromMs` | int | 0 | 起始时间（含） |
| `toMs` | int | 0 | 结束时间（含）；`0` 表示不限 |
| `limit` | int | 2000 | 1–5000（硬上限） |

```powershell
curl.exe "$BASE/api/v1/danmaku/videos/1001/history?fromMs=0&toMs=30000&limit=2000"
```

```json
{ "code": 0, "message": "success", "data": { "videoId": "1001", "fromMs": 0, "toMs": 30000, "count": 2,
  "items": [
    { "danmakuId": 2001, "timeMs": 1500,  "content": "开场了",   "color": "#FFFFFF", "position": "SCROLL", "uid": "u-2001", "sentAt": "2026-09-20T10:00:00+08:00", "status": "NORMAL" },
    { "danmakuId": 2002, "timeMs": 15000, "content": "这里是重点", "color": "#FF0000", "position": "TOP",    "uid": "u-3001", "sentAt": "2026-09-20T10:05:00+08:00", "status": "NORMAL" } ] } }
```

> 单次硬上限 5000 条：超过说明数据异常或遭攻击，宁可截断（响应头 `X-Result-Truncated: true`）也不让单请求拖垮服务。

### 4.3 `GET /api/v1/danmaku/stats` —— 房间弹幕统计

无需鉴权。`?roomId=5001`：

```json
{ "code": 0, "message": "success", "data": { "roomId": "5001", "total": 3421, "hotCount": 500, "lastSentAt": "2026-09-27T20:31:05.412+08:00" } }
```

## 5. 管理接口（均需 `X-User-Role: ADMIN`）

### 5.1 `POST /api/v1/danmaku/admin/reload-words` —— 热重载词库

```powershell
curl.exe -X POST "$BASE/api/v1/danmaku/admin/reload-words" @ADM
```

```json
{ "code": 0, "message": "success", "data": { "words": 7, "reloadedAt": "2026-09-27T20:00:00+08:00" } }
```

`words` 是本次加载成功的词条数，与 `/readyz` 的 `filter.detail` 一致。非 ADMIN → `403 {"code":40301,"message":"需要管理员权限","data":null}`。

### 5.2 `GET /api/v1/danmaku/admin/words` —— 查看敏感词

```powershell
curl.exe "$BASE/api/v1/danmaku/admin/words" @ADM
```

```json
{ "code": 0, "message": "success", "data": { "items": [
  { "id": 1, "word": "广告词示例", "strategy": "REJECT",  "enabled": true },
  { "id": 2, "word": "测试词",     "strategy": "REPLACE", "enabled": true } ] } }
```

### 5.3 `POST /api/v1/danmaku/admin/words` —— 新增敏感词

```powershell
curl.exe -X POST "$BASE/api/v1/danmaku/admin/words" @ADM `
  -H "Content-Type: application/json" -d '{"word":"新词","strategy":"REJECT"}'
```

```json
{ "code": 0, "message": "success", "data": { "id": 3, "word": "新词", "strategy": "REJECT", "enabled": true } }
```

> 新增后**自动触发一次热重载**，无需再调 `reload-words`；词已存在 → `409 {"code":40901,"message":"敏感词已存在: 新词","data":null}`。

## 6. WebSocket 协议

### 6.1 连接

```text
ws://localhost:9003/ws/danmaku?roomId=5001&uid=u-2001&nickname=小明
ws://localhost:9003/ws/danmaku?videoId=1001
```

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `roomId` / `videoId` | 二选一 | 订阅直播房间 / 点播视频 |
| `uid` | 否 | 为空即游客（只读） |
| `nickname` | 否 | 展示昵称 |

握手成功首帧：

```json
{ "type": "welcome", "data": { "clientId": "c-8f2a1b", "roomId": "5001", "uid": "u-2001", "readOnly": false, "onlineCount": 128, "hotCount": 500, "serverTime": "2026-09-27T20:00:00+08:00" } }
```

握手失败（HTTP 400 / 403，不升级连接）：`{"code":40001,"message":"必须提供 roomId 或 videoId","data":null}`、`{"code":80003,"message":"直播间当前未开播","data":null}`。

### 6.2 客户端 → 服务端

```json
{ "type": "danmaku", "data": { "content": "好耶", "color": "#FFFFFF", "position": "SCROLL", "timeMs": 0, "clientMsgId": "c-0002" } }
{ "type": "ping", "data": {} }
```

> `roomId` / `videoId` 以握手参数为准，**帧内无需重复传**（防跨房间注入）。

### 6.3 服务端 → 客户端

```json
{ "type": "danmaku", "data": { "danmakuId": 0, "clientMsgId": "c-0002", "roomId": "5001", "videoId": "", "uid": "u-2001", "nickname": "u-2001", "content": "好耶", "color": "#FFFFFF", "position": "SCROLL", "timeMs": 0, "sentAt": "2026-09-27T20:00:02.001+08:00", "status": "NORMAL" } }
{ "type": "pong",   "data": { "serverTime": "2026-09-27T20:00:30+08:00" } }
{ "type": "system", "data": { "event": "LIVE_STARTED", "message": "直播已开始", "at": "2026-09-27T20:00:00+08:00" } }
{ "type": "system", "data": { "event": "LIVE_ENDED",   "message": "直播已结束", "at": "2026-09-27T22:31:05+08:00" } }
{ "type": "error",  "data": { "code": 80002, "message": "发送过于频繁", "retryAfterMs": 640 } }
{ "type": "error",  "data": { "code": 80001, "message": "弹幕包含违规内容" } }
```

### 6.4 连接生命周期

| 事件 | 行为 |
| --- | --- |
| 连接建立 | 注册到房间 Hub，回 `welcome` |
| 客户端 30s 未发 ping | 服务端每 30s 发 WebSocket Ping 帧探测（`ping_period: 30s`） |
| 60s 无任何入站帧（Pong 或业务帧） | 关闭连接（`close` 1001，`pong_wait: 60s`） |
| 同一 uid 第 4 条连接 | 关闭该 uid 最旧的连接（`close` 4001） |
| 连续 3 次协议解析失败 | 关闭连接（`close` 1003） |
| 服务端优雅退出 | 广播 `system: SERVER_SHUTDOWN` 后关闭 |

**客户端示例（JavaScript）**

```javascript
const ws = new WebSocket("ws://localhost:9003/ws/danmaku?roomId=5001&uid=u-2001&nickname=小明");
ws.onmessage = (e) => {
  const frame = JSON.parse(e.data);
  if (frame.type === "welcome") console.log("已连接", frame.data);
  if (frame.type === "danmaku") render(frame.data);
  if (frame.type === "system")  console.log("系统消息", frame.data);
  if (frame.type === "error")   console.warn("发送失败", frame.data);
};
ws.send(JSON.stringify({ type: "danmaku", data: { content: "好耶", clientMsgId: crypto.randomUUID() } }));
setInterval(() => ws.send(JSON.stringify({ type: "ping", data: {} })), 30000);
```

## 7. 端到端验收脚本

```powershell
$BASE = "http://localhost:9003"; $U1 = "u-2001"; $U2 = "u-3001"

curl.exe "$BASE/healthz"; curl.exe "$BASE/readyz"                    # 0) 探针；确认 filter.words > 0

curl.exe -X POST "$BASE/api/v1/danmaku/send" -H "Content-Type: application/json" `
  -d '{"roomId":"5001","content":"游客弹幕"}'                        # 1) 应 401 / 40101

curl.exe -X POST "$BASE/api/v1/danmaku/send" -H "X-User-Id: $U1" -H "Content-Type: application/json" `
  -d '{"roomId":"5001","content":"第一条弹幕","clientMsgId":"acc-001"}'   # 2) 正常发送

curl.exe -X POST "$BASE/api/v1/danmaku/send" -H "X-User-Id: $U1" -H "Content-Type: application/json" `
  -d '{"roomId":"5001","content":"第一条弹幕","clientMsgId":"acc-001"}'   # 3) 幂等：只产生一条

1..7 | ForEach-Object { curl.exe -s -X POST "$BASE/api/v1/danmaku/send" -H "X-User-Id: $U1" `
  -H "Content-Type: application/json" -d "{`"roomId`":`"5001`",`"content`":`"刷屏 $_`"}" }   # 4) 应出现 80002

curl.exe "$BASE/api/v1/danmaku/rooms/5001/history?page=1&pageSize=50"  # 5) 第 1 页走热数据
curl.exe "$BASE/api/v1/danmaku/stats?roomId=5001"
curl.exe -X POST "$BASE/api/v1/danmaku/send" -H "X-User-Id: $U2" -H "Content-Type: application/json" `
  -d '{"videoId":"1001","content":"这里是重点","timeMs":15000,"position":"TOP","color":"#FF0000"}'  # 6) 点播
curl.exe "$BASE/api/v1/danmaku/videos/1001/history?fromMs=0&toMs=30000"
curl.exe -X DELETE "$BASE/api/v1/danmaku/1" -H "X-User-Id: u-9999"     # 7) 他人撤回 → 403
curl.exe -X DELETE "$BASE/api/v1/danmaku/1" -H "X-User-Id: $U1"        #    本人撤回 → 200
```

**WebSocket 验证（两个标签页各执行一次，第二个换 `uid=u-3001`）**

```javascript
const ws = new WebSocket(`ws://localhost:9003/ws/danmaku?roomId=5001&uid=u-2001`);
ws.onmessage = e => { const f = JSON.parse(e.data);
  if (f.type === "danmaku") console.log("[收到弹幕]", f.data.content, "from", f.data.uid);
  if (f.type === "welcome") console.log("[欢迎]", f.data); };
setTimeout(() => ws.send(JSON.stringify({ type: "danmaku", data: { content: "跨连接测试", clientMsgId: crypto.randomUUID() } })), 2000);
```

**点播弹幕渲染（示意）**

```javascript
const items = (await (await fetch("http://localhost:9003/api/v1/danmaku/videos/1001/history?fromMs=0&toMs=600000")).json()).data.items;
const video = document.querySelector("video");
let cursor = 0;
video.addEventListener("timeupdate", () => {
  const nowMs = video.currentTime * 1000;
  while (cursor < items.length && items[cursor].timeMs <= nowMs) renderToScreen(items[cursor++]);  // 按 timeMs 升序投放
});
```

**期望结果**

| 步骤 | 期望 |
| --- | --- |
| 探针 | `/healthz` 200；`/readyz` 四项全 UP 且 `filter.words > 0` |
| 游客发送（1） | `401 / 40101`，且 MySQL 无新增行、无广播帧 |
| 正常发送（2） | `code=0`、`danmakuId=0`、`persisted=true`；同房间 WS 收到 `danmaku` 帧 |
| 幂等（3） | 与步骤 2 返回相同 `sentAt`，`media_danmaku` 只多 1 行 |
| 连发 7 条（4） | 同秒内第 6 条及以后 `429 / 80002`（前 5 条受用户级 5 条/秒保护） |
| 历史（5） | 倒序、含刚发弹幕、`source=hot` |
| 撤回（7） | 他人 `403 / 40301`；本人 200 且历史中消失（`status=RECALLED`） |

## 8. 与另外两个 Go 服务的衔接

| 依赖 | 方向 | 方式 |
| --- | --- | --- |
| `live-service-go` | 订阅 | 消费 `live.started` / `live.stopped`（见下方契约） |
| `live-service-go` | **无同步调用** | 直播状态只读本地 Redis `danmaku:live:{roomId}`，不调 `live-service`；两个 Go 服务之间只有 RabbitMQ topic 事件 |
| `video-service-go` | 无同步调用 | 点播弹幕不校验视频存在性（阶段一避免跨服务调用，属已知取舍） |
| Java 网关 | 被调用 | `/api/v1/danmaku/**` 直连 `:9003`（未接 Nacos）；`/ws/danmaku` 需网关支持 WS 透传与 `?access_token=` 鉴权 |

```text
live.started → payload: { roomId, ownerId, sessionId, title, coverUrl, startedAt }
   本服务动作：1. SET danmaku:live:{roomId} = 1
              2. DEL danmaku:room:{roomId}:recent（清理上一轮）
              3. 若该房间有活跃连接，广播 system: LIVE_STARTED

live.stopped → payload: { roomId, sessionId, endedAt, durationSec, peakOnline, viewerTotal, reason }
   本服务动作：1. SET danmaku:live:{roomId} = 0（写 0 而不是删键，避免状态退化回「未知」被放行）
```

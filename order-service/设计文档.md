## order-service 需求：

```
order-service
│
├── 1. 创建订单

├── 3. 查询我的订单

```

## 订单状态机：

```
WAIT_PAY
   │
   │ 支付成功
   ↓
PAID
   │
   │ 权益发放完成
   ↓
COMPLETED


WAIT_PAY
   │
   │ 用户取消 / 超时
   ↓
CANCELLED
```

| 状态        | 含义   |
| ----------- | ------ |
| `WAIT_PAY`  | 待支付 |
| `PAID`      | 已支付 |
| `COMPLETED` | 已完成 |
| `CANCELLED` | 已取消 |

## HTTP接口：

| HTTP                              | 用途         | 登录     |
| --------------------------------- | ------------ | -------- |
| `POST /api/v1/orders`             | 创建订单     | ✅        |
| `GET /api/v1/orders/{id}`         | 查询订单详情 | ✅        |
| `GET /api/v1/orders`              | 查询我的订单 | ✅        |
| `POST /api/v1/orders/{id}/cancel` | 取消订单     | ✅        |
| `POST /api/v1/orders/{id}/pay`    | 创建支付单   | ✅        |
| `POST /api/v1/payments/callback`  | 支付回调     | ❌        |
| —                                 | 超时取消     | 定时任务 |

## 数据库中表：

```
product-service
    │
    ├── product
    ├── sku
    └── inventory
            ↓
        同一个 MySQL DB
            ↑
    order-service
    │
    ├── order
    ├── order_item
    ├── payment_order
    └── payment_record
```

`product/sku/inventory` 的数据所有权仍然属于 `product-service`。 `order-service` 通过 RPC 调 `product-service` 操作商品和库存

```
order-service
│
├── order
│
├── order_item
│
├── payment_order
│
└── payment_record
```

关系：

```
order:谁在什么时候创建了哪个订单，这个订单多少钱，现在处于什么状态？
  │
  │ 1 : N
  ↓
order_item:这个订单具体买了什么？


order
  │
  │ 1 : N / 1 : 1
  ↓
payment_order:支付单
  │
  │ 1 : N
  ↓
payment_record:记录支付渠道交互和回调历史。
```

```sql
CREATE TABLE `order` (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,

    order_id VARCHAR(32) NOT NULL UNIQUE,

    uid VARCHAR(32) NOT NULL,

    status TINYINT NOT NULL DEFAULT 0,

    total_amount BIGINT NOT NULL,

    expire_at DATETIME NULL,

    paid_at DATETIME NULL,

    completed_at DATETIME NULL,

    cancelled_at DATETIME NULL,

    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,

    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
        ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_uid_created_at (uid, created_at),

    INDEX idx_status_expire_at (status, expire_at)
);
```

```sql
CREATE TABLE `order_item` (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,

    order_id BIGINT NOT NULL,

    product_id BIGINT NOT NULL,

    sku_id BIGINT NOT NULL,

    product_name VARCHAR(128) NOT NULL,

    sku_name VARCHAR(128) NOT NULL,

    unit_price BIGINT NOT NULL,

    quantity INT NOT NULL,

    total_amount BIGINT NOT NULL,

    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,

    INDEX idx_order_id (order_id),

    INDEX idx_product_id (product_id),

    INDEX idx_sku_id (sku_id)
);
```

```sql
CREATE TABLE `payment_order` (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,

    payment_id VARCHAR(32) NOT NULL UNIQUE,

    order_id VARCHAR(32) NOT NULL,

    uid VARCHAR(32) NOT NULL,

    amount BIGINT NOT NULL,

    status TINYINT NOT NULL DEFAULT 0,

    payment_channel TINYINT NOT NULL,

    transaction_id VARCHAR(128) NULL,

    expire_at DATETIME NULL,

    paid_at DATETIME NULL,

    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,

    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
        ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_transaction_id (transaction_id),

    INDEX idx_order_id (order_id),

    INDEX idx_uid_created_at (uid, created_at)
);
```

```sql
CREATE TABLE `payment_record` (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,

    payment_id VARCHAR(32) NOT NULL,

    transaction_id VARCHAR(128) NULL,

    payment_channel TINYINT NOT NULL,

    callback_status TINYINT NOT NULL,

    callback_data TEXT NULL,

    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,

    INDEX idx_payment_no (payment_no),

    INDEX idx_transaction_id (transaction_id)
);
```

## 需要实现的需求:

| 模块     | 主要需求                   | 优先级 |
| -------- | -------------------------- | ------ |
| 用户创建 | 创建用户基础资料           | P0     |
| 用户信息 | 查询、修改用户资料         | P0     |
| 用户状态 | 正常、禁用、注销等状态管理 | P0     |
| 用户注销 | 用户主动注销账号           | P0     |
| 用户查询 | 单个/批量查询用户          | P0     |

```
P0
├── 1. 创建用户
├── 2. 获取当前用户信息
├── 3. 根据 ID 查询用户
├── 4. 批量查询用户
├── 5. 判断用户是否存在
├── 6. 修改用户资料
├── 7. 查询用户状态
├── 8. 用户注销
└── 9. 管理员管理用户状态

P1
├── 10. 用户信息变更通知
├── 11. 用户搜索
└── 12. 用户资料扩展
```

### auth-service

```
CREATE TABLE account (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    username VARCHAR(32),
    phone VARCHAR(20),
    email VARCHAR(254),
    password_hash VARCHAR(100) NOT NULL,
    status TINYINT NOT NULL DEFAULT 1,
    created_at DATETIME NOT NULL,
    updated_at DATETIME NOT NULL,

    UNIQUE KEY uk_username (username),
    UNIQUE KEY uk_phone (phone),
    UNIQUE KEY uk_email (email)
);
```

### user-service

```
CREATE TABLE user (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    uid VARCHAR(32) NOT NULL,
    nickname VARCHAR(64),
    avatar VARCHAR(512),
    gender TINYINT,
    bio VARCHAR(255),
    status TINYINT NOT NULL DEFAULT 1,
    created_at DATETIME NOT NULL,
    updated_at DATETIME NOT NULL,

    UNIQUE KEY uk_uid (uid)
);
```

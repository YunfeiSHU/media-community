### auth-service

```
CREATE TABLE account (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    uid VARCHAR(32) NOT NULL,
    username VARCHAR(32),
    phone VARCHAR(20),
    email VARCHAR(254),
    password_hash VARCHAR(100) NOT NULL,
    status TINYINT NOT NULL DEFAULT 1,
    created_at DATETIME NOT NULL,
    updated_at DATETIME NOT NULL,

    UNIQUE KEY uk_username (username),
    UNIQUE KEY uk_phone (phone),
    UNIQUE KEY uk_email (email),
    UNIQUE KEY uk_uid (uid)
);
```

> 与 `auth-service/src/main/resources/schema.sql` 保持一致：
> 早期设计里用 `user_id BIGINT` 关联用户中心，实际实现改成 `uid VARCHAR(32)`——
> 跨服务只传业务编号，不依赖对方的自增主键。
> `username` 目前恒为 NULL（只支持手机号 / 邮箱注册），保留列与唯一索引给将来的用户名登录。

### user-service

```
CREATE TABLE user (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    uid VARCHAR(32) NOT NULL,
    nickname VARCHAR(64),
    avatar VARCHAR(512),
    gender VARCHAR(16),
    bio VARCHAR(500),
    role TINYINT NOT NULL DEFAULT 1,
    status TINYINT NOT NULL DEFAULT 1,
    created_at DATETIME NOT NULL,
    updated_at DATETIME NOT NULL,

    UNIQUE KEY uk_uid (uid)
);
```

> 与 `src/main/resources/schema.sql` 保持一致：
> `gender` 用字符串（如 `MALE`）存储所以是 `VARCHAR(16)`；
> `bio` 为 `VARCHAR(500)`（与 DTO 的 `@Size(max = 500)` 对齐）；
> 另有 `role`（0 = 管理员，1 = 普通用户）。
